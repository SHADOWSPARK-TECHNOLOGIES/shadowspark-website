# ShadowSpark Privacy Policy (Operational Baseline)

This baseline governs data handling for ShadowSpark product and collaborator systems, including rewards attribution.

## Data Minimization
- Collect only data required to deliver product functionality, trust operations, and rewards attribution.
- Do not store sensitive identifiers when a hashed or scoped identifier is sufficient.

## Lawful Use and Consent
- Personal data use must map to a documented legal basis (contract, consent, or legitimate interest).
- Consent-dependent flows must provide clear opt-in and opt-out controls.

## Retention
- Retain operational telemetry only for the minimum useful window.
- Rewards events must be retained only for audit and attribution requirements, then archived or deleted on schedule.

## Access Control
- Access is role-based and least-privilege by default.
- Admin pathways require authenticated access and must not be publicly indexed.

## Security Controls
- Enforce CSRF protection and CAPTCHA on high-risk interaction endpoints.
- Preserve domain and sender integrity controls (DMARC, SPF, continuous domain monitoring).
- Log security-relevant events with enough context for incident response.

## User Rights
- Provide pathways for access, correction, and deletion requests where applicable.
- Export user data in a structured format upon validated request.

## Incident Handling
- Incidents involving personal data require timely triage, containment, and documented remediation.
- Post-incident reviews must include root-cause analysis and preventive control updates.
